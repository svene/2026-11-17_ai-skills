The changes made when copying:

- **Layout:** one Technology module `inbound-http-json-vm` instead of one `inbound/web` package. Shared code goes in `cross.htmlrender` and `cross.devreload`, and each component (VM, Receiver, template) in `feature.<x>`.
- **Names:** `UiRouteName` / `UiEventName` replace the per-feature `JTSPerson*` enums; `HtmxHeaders` replaces `HTMXConsts`; view models are `*VM` records.
- **Dispatch:** `UiRouteReceiver` and the `UiRouteSource` interface replace the single `PersonUIResource`, so each feature contributes its routes. A route served twice or not at all fails the boot.
- **Mutation URLs:** the typescript-generator JAX-RS client (`web-api.ts`, wrapped by `api.ts`) replaces the source's `HonoWebApiSharedConsts` and its gmavenplus generation step, following [#17](https://github.com/svene/2026-11-17_ai-skills/issues/17) and its branch `research/typescript-generator-jaxrs`; gmavenplus is dropped ([#18](https://github.com/svene/2026-11-17_ai-skills/issues/18)).
- **Build:** `frontend-maven-plugin` with a pinned Node replaces the source's system Node and `watch.ts`. It runs `npm ci --ignore-scripts`, `tsc --noEmit` and esbuild inside `mvn verify`; `npm run watch` is esbuild's own `--watch`.
- **htmx:** vendored at a versioned path (`js/htmx/4.0.0/htmx.js`).
- **Errors:** an invalid form answers 400 with its own envelope and an `errors` map, rendered by the form's template. A 5xx is never swapped; `#error-banner` shows it, tracked per element so that concurrent re-fetches cannot hide another element's failure. The source has neither.
- **`hx-hono.ts`:** also checks that the JSON is an envelope (`route` is a string) before rendering it.
- **Example:** a guestbook (list plus sign form) in triptych's `feature.example` replaces the person CRUD.
- **Tests:** `ExampleUiTest` (RestAssured on the envelopes) replaces nothing in the source. The source's Playwright specs are left to the Playwright skill.
